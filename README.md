# 網站自動化流程設計平台 (Automation Studio)

專為 Windows 環境設計的視覺化網站自動化流程設計、錄製、除錯與執行平台。支援以直覺的圖形化介面建立 Playwright 瀏覽器自動化腳本、接管現有 Chrome 瀏覽器（CDP）、多層 Frame 智慧錄製、批次參數下載，並可一鍵匯出為獨立 TypeScript 專案或 AI Agent 技能模組。

---

## 快速開始

### 1. 系統需求
* **作業系統**：Windows 10 / Windows 11 (x64)
* **執行環境**：已安裝 Node.js 20+（或於專案內配置 `runtime\node\` 可攜式環境）
* **瀏覽器**：Google Chrome 或隨附 Playwright Chromium

### 2. 啟動方式
1. **首次使用環境設定（選用）**：
   * 雙擊執行 `setup-runtime.bat`，系統會自動檢查並安裝所需的 Playwright Chromium 瀏覽器核心。
   * *企業內網環境*：腳本預設啟用 `NODE_USE_SYSTEM_CA=1`，自動讀取 Windows 本機信任憑證庫，相容公司內部 HTTPS 檢驗憑證。
2. **啟動平台**：
   * 雙擊執行根目錄的 **`start.bat`**。
   * 服務啟動後，瀏覽器將自動開啟管理介面：[http://127.0.0.1:4173](http://127.0.0.1:4173)。
   * （若需使用傳統 EBAS 報表功能，可直接存取 [http://127.0.0.1:4173/legacy/](http://127.0.0.1:4173/legacy/) 或執行 `start-ebas-ui.bat`）。
3. **停止服務**：
   * 關閉命令提示字元視窗，或雙擊執行 `stop.bat`。

## 核心功能介紹

### 1. 視覺化流程設計器 (Automation Designer)
* **豐富動作支援**：支援開啟網址、點擊、雙擊、輸入文字、下拉選單、勾選/取消、檔案上傳、鍵盤快捷鍵、滑鼠懸停 (Hover)、元素等待、條件分支 (If/Else)、迴圈與延遲等待等。
* **動態參數與變數傳遞**：
  * 支援以 `{{參數名稱}}` 引用輸入參數或前置步驟擷取出的動態變數。
  * 支援敏感資料遮罩標記，避免密碼或機敏個資顯示於介面或匯出檔中。
* **網頁資料與驗證碼擷取**：
  * 「擷取文字」：可讀取頁面文字、HTML 或標籤屬性存入流程變數。
  * 「擷取樣式 (Regex)」：可由變數中使用正規表達式提取內容（例如自動擷取驗證簡訊或通知信中的 6 位數驗證碼）。
  * 「複製至剪貼簿」：支援將文字或變數複製到系統剪貼簿。
* **便捷編輯工具**：支援步驟卡片滑鼠拖曳排序、單步複製（快捷鍵 `Ctrl+Shift+D`）、步驟上移/下移（`Alt+↑/↓`），以及批次全選啟用/停用。

### 2. 瀏覽器工作站與智慧錄製器 (Browser Recorder)
* **所見即所得錄製**：在可視瀏覽器中操作網頁，自動攔截點擊、輸入、選單選取與檔案下載，並即時產生日誌與候選 Selector。
* **多層 Frame 與舊式系統相容**：
  * 深度支援多層 `<iframe>`、動態頁面更新與 Frame 重建架構（如 SmartKMS、ExtJS、內部公文系統）。
  * 具備 Frame 生命週期健康檢查與自動修復注入機制，錄製事件自動帶有完整 FramePath。
* **保留登入狀態 (Profile)**：
  * 預設開啟「保留登入狀態」，同一專案的錄製與執行共用本機持久化 Chromium Profile。
  * 關閉瀏覽器後仍保留 Cookie 與工作階段，免去每次重複登入的繁瑣操作。

### 3. 接管現有 Chrome 瀏覽器 (CDP 模式)
* **無縫接軌日常登入**：針對具備複雜 MFA、簡訊 OTP、硬體憑證或 CAPTCHA 驗證碼的網站，可直接接管您已手動登入好的 Chrome 視窗。
* **一鍵快速啟用**：
  * 雙擊執行 `start-chrome-cdp.bat`（或在工作站設定開啟「執行時自動啟動 Chrome」）。
  * CDP 預設連線位置：`http://127.0.0.1:9222`（嚴格限制本機回環位址，確保安全性）。
* **無干擾生命週期**：自動化腳本執行完畢後僅中斷 CDP 控制通道，**不會關閉**使用者的 Chrome 分頁。

### 4. 測試與單步除錯 (Test & Debug)
* **彈性執行模式**：支援「整段流程執行」、「只執行此步驟」及「從此步驟開始執行」，無須從頭重跑即可快速除錯特定步驟。
* **人工操作等待機制 (Human-in-the-loop)**：
  * 當自動化流程遇到人機驗證或安全檢查時，流程可進入「等待人工操作」狀態。
  * 支援三種恢復條件：使用者手動點擊「繼續執行」、指定網頁元素出現、或網址跳轉符合條件。
* **完整除錯證據保存**：
  * 步驟執行失敗時，自動記錄失敗原因、前後事件、Console 日誌、網路請求、DOM 快照與頁面截圖。
  * 提供「下載失敗診斷包 ZIP」，方便外部人員或技術支援快速定位問題。

### 5. 批次下載與任務管理 (Batch Runner)
* **表格化參數輸入**：支援多筆參數清單建檔、匯入與批次排程執行。
* **智慧檔案下載沉積**：
  * 支援直接下載連結分析與預覽頁 PDF 自動捕獲，避免因下載彈窗而阻塞流程。
  * 檔案自動儲存至專案 `downloads/` 目錄，支援動態命名與自動檔名碰撞編號處理。
* **執行紀錄管理**：支援單筆/批次刪除、篩選器清除，並能監控磁碟空間占用。

### 6. 多格式成果匯出 (Export)
設計好的流程可自由匯出為以下一種或多種成果：
| 匯出成果類型 | 適用場景與特色 |
| :--- | :--- |
| **可攜工作流程 (ZIP)** | 包含 `workflow.json`、參數定義 Schema、Selector 清單與說明文件，可直接匯入至其他 Automation Studio 環境。 |
| **獨立 TypeScript 專案** | 完整的獨立 Playwright TypeScript 專案（自帶 package.json、runner 與啟動 bat），可完全脫離 Studio 介面，部署於獨立伺服器、排程工作或 CI/CD 流水線。 |
| **AI Agent SKILL.md** | 依標準 Agent Skill 格式輸出，方便 Antigravity、Claude Code、Cursor 或 Codex 等 AI 助手理解流程並進行排程操作。 |

*(註：所有匯出成果皆會自動清除個人 Cookie、Token、本機 Profile 及機敏預設值，保障資料安全。)*

### 7. AI 輔助流程助理 (選用)
* 支援介接 OpenAI、Google Gemini、本機 Ollama 或企業自建 AI Gateway。
* 可透過自然語言描述自動化需求，由 AI 檢視網站元素並產生初版流程草稿；支援多輪對話修改與差異比對確認。

## 標準操作路徑

1. **建立專案**：在「專案總覽」點擊「新增專案」，輸入專案名稱與起始目標網址。
2. **設定允許網域**：在「網站與工作站」確認「允許網域」（安全防護機制，避免腳本跳轉至未授權網域）。
3. **啟動瀏覽器與登入**：點擊「開啟工作站瀏覽器」，在彈出的視窗中手動完成網站帳密、MFA 或憑證登入。
4. **錄製流程**：點擊「開始錄製」，於網頁上執行目標操作（點擊、輸入、下載），完成後點擊「將錄製事件加入流程」。
5. **微調流程細節**：切換至「自動化設計器」，微調步驟等待條件、參數替換變數、或加入 If 判斷與迴圈。
6. **測試與除錯**：切換至「測試與 Debug」執行流程，確認每一步驟狀態與下載成果。
7. **批次執行或匯出**：切換至「批次任務」填入資料批量執行，或於「發布與版本」匯出為獨立 TypeScript 腳本。

## 重要注意事項與安全規範

* **登入憑證與驗證碼處理**：
  * 本平台嚴格遵循安全規範：**不自動破解驗證碼、不繞過 MFA、不保存明文密碼**。
  * 遇到圖形驗證碼或 OTP 驗證時，請搭配「人工操作步驟」由使用者於瀏覽器中手動完成。
* **允許網域安全白名單**：
  * 執行流程前系統會檢查所有跳轉網址。若重新導向至非允許網域，流程將主動中斷以確保安全性。
  * 支援萬用子網域設定（例如 `*.example.com`）。
* **企業憑證環境設定**：
  * 若處於具備 HTTPS 檢驗的公司內網，預設已開啟 `NODE_USE_SYSTEM_CA=1`。
  * 若仍出現憑證問題，請向 IT 部門取得根憑證 (.pem/.cer)，並於 `.env` 中設定 `NODE_EXTRA_CA_CERTS=C:\path\to\ca.pem`，切勿隨意停用 TLS 安全驗證。
* **資料目錄與儲存維護**：
  * 專案與流程設定：`data\studio\projects\`
  * 檔案下載成果：`downloads\`
  * 測試除錯證據與截圖：`debug\studio\`
  * 瀏覽器登入快取：`data\profiles\`
  * 系統預設定期清理過期 Debug 檔案，亦可於「系統設定」手動點擊「立即清理」。

## 專案結構說明

```text
automation-studio-generic/
├── public/                 # 前端 UI 靜態資源 (HTML / CSS / JavaScript)
├── src/                    # 後端原始碼 (TypeScript)
│   ├── adapters/           # 瀏覽器與報表轉接器 (Playwright, Chromium, EBAS)
│   ├── studio/             # 流程設計器核心 (執行器、錄製器、CDP、AI 助理、匯出器)
│   ├── services/           # 核心業務邏輯與儲存服務
│   └── ui/server.ts        # 本機 Web 伺服器與 API 路由 (預設 Port 4173)
├── data/                   # 專案定義與使用者設定 (排除於 Git 追蹤)
├── downloads/              # 下載檔案存放目錄 (排除於 Git 追蹤)
├── graphify-out/           # Graphify 架構知識圖譜產出物 (graph.html, GRAPH_REPORT.md)
├── start.bat               # 平台啟動批次檔
├── start-chrome-cdp.bat    # Chrome 遠端除錯啟動批次檔
├── setup-runtime.bat       # 執行環境與瀏覽器安裝檢測批次檔
└── stop.bat                # 平台停止批次檔
```
